Deployment guide — Flutter web → Firebase Hosting

Goal
- Build Flutter web and deploy to Firebase Hosting, so staff can access monitoring via a public link.

Prerequisites
- Node.js + npm
- Firebase CLI: `npm install -g firebase-tools`
- Flutter SDK
- A Firebase project configured (you should have `firebase_options.dart` generated by `flutterfire configure`)
- You must be logged in to Firebase CLI: `firebase login`

Quick commands (manual)
1. Install deps

```bash
flutter pub get
npm install -g firebase-tools
```

2. Build web

```bash
flutter build web --release
```

3. Init hosting (first time only)

```bash
firebase init hosting
# - choose your project
# - set 'build/web' as public directory
# - choose single-page app: Yes
```

4. Deploy

```bash
firebase deploy --only hosting
```

PowerShell helper (Windows)
- Use `deploy_windows.ps1` in project root. Example:

```powershell
# run from project root
.\deploy_windows.ps1
# or skip build if you already built
.\deploy_windows.ps1 -SkipBuild
```

Security notes
- For public monitoring: set Firestore rules to allow read on `stocks` and `stores` and restrict write to authenticated users.
- For admin writes: create admin accounts in Firebase Console (Authentication).
- For production: use custom claims and stricter rules; enable MFA for admin accounts.

Troubleshooting
- "firebase not found": make sure `npm` global bin is in PATH.
- "Build output not found": ensure `flutter build web` succeeded and `build/web` exists.
- Rules/Permissions errors: check Firestore rules and ensure the admin is signed in.

Functions & audit logging
- To enable audit logs for stock updates, deploy Cloud Functions from `functions/`:

```bash
cd functions
npm install
firebase deploy --only functions
```

- The Cloud Function `onStockUpdate` writes change logs to `stock_logs` whenever a `stocks/{id}` document updates.

Create admin users programmatically (optional)
- If you prefer to create admin accounts via script (requires service account key JSON):

```bash
# install admin SDK if needed
npm install firebase-admin
node tools/create_admin.js path/to/serviceAccountKey.json admin@example.com S3cretPass
```

This script will create the user and set `customClaims.admin = true`.
